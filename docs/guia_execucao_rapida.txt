FIAP - TECH CHALLENGE FASE 4 - GUIA RÁPIDO WINDOWS / POWERSHELL

1) Extraia o ZIP e entre na pasta:
   cd "C:\Projetos\fiap-tech-challenge-fase4"

2) Ambiente:
   py -3.12 -m venv .venv
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   .\.venv\Scripts\Activate.ps1
   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt
   Copy-Item .env.example .env

3) Download manual:
   https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce/data
   Extraia todos os CSVs dentro de data\raw\
   ALTERNATIVA CLI: kaggle datasets download -d olistbr/brazilian-ecommerce -p data/raw --unzip

4) Dados e índice:
   python scripts/00_check_data.py
   python scripts/01_prepare.py
   python scripts/03_eda.py
   python scripts/02_index.py --rebuild --limit 5000
   python scripts/04_smoke_test.py

5) Respostas com LLM:
   Instale Ollama: https://ollama.com/download/windows
   ollama pull llama3.2:3b
   python -m streamlit run app.py

6) Testes:
   python -m pytest -q
   python scripts/05_evaluate.py

7) Corpus completo:
   python scripts/02_index.py --rebuild

8) Git:
   git config --global user.name "SEU NOME"
   git config --global user.email "SEU_EMAIL_DO_GITHUB"
   git init
   git branch -M main
   git add .
   git commit -m "Entrega Tech Challenge Fase 4 - RAG Olist"
   gh auth login
   gh repo create fiap-tech-challenge-fase4 --public --source=. --remote=origin --push
